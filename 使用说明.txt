光标  Cursors 1.3.0
========================================================================

一键切换整套 Windows 鼠标指针的小工具。内置 60 套光标样式，另有
11,548 套社区光标可在线浏览下载。本版本增加了简体中文界面、语言切换
和明暗皮肤。


一、运行
------------------------------------------------------------------------
1. 把整个文件夹解压到任意位置，Cursors.exe 必须和 Packs 文件夹放在
   同一目录下，不要只单独复制 exe。
2. 双击 Cursors.exe 即可，无需安装，不需要管理员权限。
3. 要求 Windows 10 / 11（自带 .NET Framework 4.8），无需另装运行库。

首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」：本程序未做
代码签名，选择「更多信息」→「仍要运行」即可。可核对同目录下压缩包附带的
.sha256 校验值。

首次启动会在开始菜单和桌面创建快捷方式，方便从 Windows 搜索里打开。


二、本版新增功能
------------------------------------------------------------------------
* 界面语言：标题栏右侧的地球按钮（显示「中文」/「EN」/「自动」）
  - 跟随系统语言（默认）：中文 Windows 自动显示中文
  - 简体中文 / English：强制指定语言
  - 切换立即生效，无需重启

* 明暗皮肤：地球按钮左边的太阳/月亮按钮，或按 Ctrl+Shift+T
  - 跟随系统主题（默认）：跟着 Windows「颜色」里的应用模式实时变化，
    已打开的窗口也不需要重启
  - 浅色 / 深色：强制指定配色
  - 手绘界面、右键菜单、标题栏和窗口边框会一起切换

* 两个选择都保存在：
  %LOCALAPPDATA%\Cursors\settings.ini
  （language=auto|zh-CN|en，theme=auto|light|dark）


三、常用操作
------------------------------------------------------------------------
应用光标        点击卡片，或用方向键 + 回车
搜索            直接开始输入，或 Ctrl+F；Esc 清空
恢复默认        标题栏「恢复默认」按钮
添加本地光标包  拖入 .zip / install.inf / .cur / .ani，或 Ctrl+O
从链接导入      Ctrl+L，或把网页链接拖进窗口
翻看更多光标    鼠标悬停在卡片上
重新扫描        F5
命令行恢复默认  Cursors.exe --restore


四、卸载
------------------------------------------------------------------------
运行 Cursors.exe --uninstall 恢复 Windows 默认光标并移除快捷方式，
然后删除本文件夹即可。如需彻底清理，再手动删除
%LOCALAPPDATA%\Cursors（含你添加过的光标包，删除前请自行备份）。
